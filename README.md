# 自制麦轮车与遥控器

以 F103 四轮底盘和按键遥控器构成控制链路，组织麦轮解算、编码器测速、PID、串口接收与通信异常保护。

**当前分支**：`main`。代表工作树。

**留存状态**：保留配套源码，待构建复核。
